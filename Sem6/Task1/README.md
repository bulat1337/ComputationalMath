Задача:
--------
Решаем жесткую систему Ван-дер-Поля

    y1' = y2,
    y2' = -a * ( y2 * (y1^2 - 1) + y1 ),

с начальными условиями
    y1(0) = 2,
    y2(0) = 0,
на отрезке [0, T], T = 20,
для a = 10^3 и a = 10^6.

Используем 4 неявных метода Рунге–Кутты:
    1) Radau IIA, порядок 1  (неявный Эйлер)
    2) Radau IIA, порядок 3
    3) Radau IIA, порядок 5
    4) SDIRK второго порядка из таблицы 4 (L-stable / асимптотически устойчивый)

Что делает программа:
---------------------
1. Реализует общую схему неявного RK-метода через таблицу Бутчера.
2. На каждом шаге решает нелинейную систему для стадий методом Ньютона.
3. Использует адаптивный шаг по правилу step-doubling:
        - один шаг длины h,
        - два шага длины h/2,
    затем оценивает локальную ошибку.
4. Сохраняет траектории в CSV-файлы.
5. Сравнивает все методы с SDIRK-методом 2-го порядка.
6. Вычисляет функцию устойчивости
        R(z) = 1 + z * b^T * (I - z A)^(-1) * e
    и записывает значения на вещественной оси в CSV-файлы.

Компиляция:
-----------
gcc -O2 -std=c11 vdp_stiff_rk.c -lm -o vdp_stiff_rk
